About the Studio

Brok3n by Design is an independent game studio where each project is designed, directed, and built by a single creator using modern creative tools. The studio brings together strange ideas, dark humor, nostalgia, and experimental mechanics. Every project explores something a little different — from retro RPGs and satirical personality tests to haunted card games and fictional radio stations.
